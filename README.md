# VIGIL — Smart Healthcare & Fall Detection Ecosystem

## Project Overview
VIGIL is a university graduation project that combines Artificial Intelligence, Machine Learning, IoT, and mobile application development to support healthcare monitoring and fall detection.

## Main Features
- Fall detection using wearable sensors.
- Vital signs monitoring.
- Machine learning-based heart disease risk estimation.
- Python backend for communication between system components.
- Flutter mobile application for displaying measurements and alerts.
- Emergency notifications and location sharing.

## Technologies
- Python
- Machine Learning
- Flask and REST APIs
- Flutter and Dart
- ESP32 and IoT sensors

## Project Components
- AI and Machine Learning
- Python Backend
- Flutter Mobile Application
- ESP32 Embedded System
- Healthcare Dataset

## Academic Project
Developed as a university graduation project during the 2025–2026 academic year.
